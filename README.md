# Dataset Used
Used penguins.csv data

# Script Name & What it does

The name of my script is assn2_rscript.R, it loads the csv and runs three descriptive analyses including summary, the mean of bill depth, and a basic histogram showing the spread of the penguins' body masses. 

# How to reproduce

In order to reproduce this analysis you need to have R studio downloaded, download the penguins.csv to your local computer, edit the path of the file to reflect the location of the file in your computer, and run the script.
